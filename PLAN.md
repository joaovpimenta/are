# ARE Roadmap

## Current baseline — complete

- Deep Adventure session module and deterministic mechanism modules.
- Real DOM/Three.js renderer seam with semantic Theme adapters.
- Shared Lab harness with lazy direct routes, reset, telemetry, hints and accessibility notes.
- Refined diegetic artifacts: Keypad, Dial, Signal Tuner, Lever Console and Cipher Rotor.
- Playable Echo Station Adventure with a local Scenario, Theme and specialized renderer.
- Manifest-driven build, pinned toolchain and layered automated verification.

## Next evidence-driven work

Future work should deepen a module only after a second real use establishes the seam.

1. Add persistence as an Adventure session adapter after an Adventure needs save/resume.
2. Add an audio renderer after two Artifacts share transport, focus and accessibility requirements.
3. Add non-linear Scene progression when a real Adventure outgrows the sequential runtime.
4. Introduce asset streaming when measured Adventure payloads justify it.
5. Add deterministic Three.js screenshots after visual states and CI GPU behavior are stable.

ADRs in `docs/adr/` record load-bearing decisions so later reviews do not re-suggest rejected or completed work.
